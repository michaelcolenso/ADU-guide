# Oregon — ADU Regulation Reference

> **Last verified:** 2026-02-26
> **Tier availability:** Foundation (top 5)
> **Status:** Active legislation

---

## Enabling Legislation

| Bill | Effective Date | Summary |
|------|---------------|---------|
| SB 1051 (2017) | 2018-01-01 | Required many Oregon cities to allow ADUs in single-dwelling areas inside UGBs; implemented through ORS 197A.425 framework. |
| HB 2001 (2019) | 2019-08-08 (signed; implementation deadlines followed) | Updated statewide housing preemption context; DLCD guidance notes ADU owner-occupancy and parking updates. |
| ORS 197A.425 (current codification) | Current | Requires covered cities/counties to allow at least one ADU per detached single-family dwelling in UGB single-dwelling zones; limits certain local restrictions. |

**Legislative history:** Oregon has long-standing ADU authorization but moved to stronger statewide minimum requirements. Current statewide baseline is codified in ORS 197A.425, while dimensional details remain mostly local so long as local standards are "reasonable" and not barred by statute.

| Type | Permitted? | Size Limit | Notes |

| Attached ADU | Yes | No statewide numeric cap | Local code sets dimensional limits. |

| JADU (internal) | No (state term not used) | N/A | Oregon statutes generally use ADU terminology. |

## Dimensional and Siting Requirements

**Maximum ADU size:** State law does not set a single statewide size cap; local jurisdictions do.
**Minimum lot size:** ORS 197A.425 does not set a statewide numeric ADU lot-size minimum; local rules apply, but covered jurisdictions must still allow at least one ADU in qualifying UGB single-dwelling zones.
**Maximum height:** Local code controls.
**Setback requirements:**
- Front: Local code
- Side: Local code
- Rear: Local code
- Special provisions: Local standards must remain "reasonable" under state law and cannot rely on prohibited owner-occupancy/off-street parking requirements in covered contexts.

**Lot coverage:** Local code.
**Floor area ratio (FAR):** Local code.

---

## Parking

**Parking required:** State-limited in covered contexts.
**Exemptions:** Oregon statewide ADU framework and DLCD guidance indicate local codes may not require additional off-street parking for ADUs in covered single-dwelling UGB areas.
**Replacement parking:** ORS 197A.425 prohibits requiring additional off-street parking for ADUs in covered contexts; it does not create a separate statewide replacement-parking mandate for converted garages.

---

## Owner-Occupancy

**Owner-occupancy required:** No (state-limited in covered contexts).
**Details:** ORS/DLCD guidance indicates local ADU rules may not impose owner-occupancy for the primary or accessory structure, with limited vacation-rental context exceptions.
**Recent changes:** DLCD notes 2019 updates addressing owner-occupancy and off-street parking requirements.

---

## Fees and Costs

**Impact fees:** ORS 197A.425 does not set a statewide ADU impact-fee cap; local system development charge and utility fee rules remain jurisdiction-specific.
**Permit fees:** Local jurisdiction fees apply.
**Utility connection fees:** Local utility authority standards apply.
**School fees:** Oregon ADU statute does not create a separate statewide ADU school-fee schedule; district/local fee treatment follows broader education and local fee law.

---

## Utility Requirements

**Separate utility meters:** Local utility and code requirements govern.
**Sewer/septic:** Local sanitary/septic approvals and capacity checks apply.
**Electrical panel:** Project-specific code compliance required.
**Water:** Local connection standards and system capacity requirements apply.

---

## Pre-Approved Plans

**State-level program:** No single statewide permit-ready ADU plan library identified.
**Notable local programs:** Eugene pre-approved ADU plan library; Portland accepts pre-approved detached ADU plans.
**Cost/time savings:** Local programs can reduce design and review time, subject to site-specific checks.

---

## Local Override Provisions

**Can cities restrict beyond state law?** Limited.
**Common local additions:** Design standards, detached height/setback controls, tree/environment overlays, utility review.
**Preemption details:** Covered cities/counties must allow at least one ADU in qualifying UGB single-dwelling areas and cannot impose prohibited owner-occupancy/off-street parking restrictions.

---

## Key City-Level Variations

### Portland
- Portland zoning allows ADUs with detailed local size and lot-context rules; city references include one- and two-ADU scenarios in some zones.
- Portland publishes ADU zoning standards and permit guidance.
- Portland maintains an ADU system development charge (SDC) waiver pathway with a recorded covenant structure.

### Eugene
- Eugene maintains a pre-approved ADU program with multiple plans available for purchase plus city-provided resources.
- City materials provide ADU due-diligence checklists and dedicated permit/zoning contacts.
- Local dimensional, utility, and SDC treatment remain city-specific.

## Key Takeaways for Homeowners

- Oregon guarantees at least one ADU in many UGB single-dwelling areas, but most dimensional numbers are local.
- State law limits local use of owner-occupancy and off-street parking mandates in covered ADU contexts.
- Portland and Eugene both provide stronger homeowner-facing ADU guidance and plan resources than many jurisdictions.
- Fees and utility requirements are still highly local, so early utility due diligence is critical.
- Confirm local code text for setbacks/height before design lock.

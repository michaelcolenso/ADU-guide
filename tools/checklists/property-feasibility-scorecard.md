# Property Feasibility Scorecard

Use this scorecard before paying for full construction drawings. Score each item from 0 to 2.

- `0` = not confirmed
- `1` = partially confirmed
- `2` = fully confirmed with documentation

## Section A: Zoning and Legal (Max 20)

| Item | Score (0-2) | Why It Matters | Notes |
|---|---:|---|---|
| ADU type allowed on parcel |  | If the type is not permitted, the project stops here. |  |
| Unit count confirmed (ADU/JADU limits) |  | Determines scope and income potential. |  |
| Setback standards confirmed |  | Most feasibility failures happen here. |  |
| Height and lot coverage confirmed |  | Controls whether your concept fits physically. |  |
| Permit path confirmed (ministerial/discretionary) |  | Drives timeline and entitlement risk. |  |
| Overlay constraints checked (flood/historic/fire/coastal) |  | Overlay review can add major delay and redesign. |  |
| HOA/CC&R review completed |  | Private rules can still affect schedule and design. |  |
| STR restrictions checked |  | Impacts revenue strategy if short-term rental is planned. |  |
| Deed/easement conflicts checked |  | Easements can block otherwise valid ADU footprints. |  |
| Local planner pre-screen completed |  | Reduces interpretation risk before design spend. |  |

## Section B: Site and Utilities (Max 16)

| Item | Score (0-2) | Why It Matters | Notes |
|---|---:|---|---|
| Primary ADU footprint identified |  | Establishes the buildable concept. |  |
| Backup footprint identified |  | Protects against first-choice rejection. |  |
| Utility routing plan drafted |  | Utility scope is a common cost overrun source. |  |
| Electrical capacity assessed |  | Panel/service upgrades can materially change budget. |  |
| Sewer/water connection approach assessed |  | Determines excavation complexity and fees. |  |
| Access/logistics constraints reviewed |  | Site access changes labor, equipment, and schedule. |  |
| Slope/drainage/tree constraints documented |  | Major drivers of redesign risk. |  |
| Early code feasibility call completed |  | Confirms assumptions before design fees escalate. |  |

## Section C: Financial Readiness (Max 14)

| Item | Score (0-2) | Why It Matters | Notes |
|---|---:|---|---|
| Baseline budget completed |  | Anchors financing and scope decisions. |  |
| Hard/soft cost split estimated |  | Improves budget realism and bid comparison. |  |
| Contingency reserve set (10-15%) |  | Absorbs predictable uncertainty. |  |
| Conservative rent case modeled |  | Prevents over-optimistic underwriting. |  |
| Break-even estimate completed |  | Tests whether timing fits goals. |  |
| Predevelopment funding identified |  | Design/permitting costs come before construction draws. |  |
| Downside scenario stress test run |  | Exposes fragile deals before commitment. |  |
